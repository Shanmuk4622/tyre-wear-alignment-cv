Start here — what to mark, and why

This is a feasibility check, not a 418-image assignment. HRNet could later learn repeatable 2-D boundary points. First we need to know whether these points are actually visible and add information beyond existing masks. PatchCore needs a defensible normal-reference set; an image that looks ordinary does not certify a healthy tyre.

  1. For each image, three horizontal guides are fixed at 25%, 50%, 75% of image height. Do not move them.
  2. At each guide, mark the left and right visible limits of the grooved tread face, where the tread turns into shoulder. Left/right means the displayed image, not vehicle side. Ignore background, lettering and paint. Do not mark a groove inside the band or use the outer tyre silhouette if the tread/shoulder transition is not distinguishable.
  3. Select a point button, then click its x-position on the image. The y-coordinate snaps to that point's guide. Use 100% or 150% display and scroll for detail. Original JPEG pixels are preserved; zoom does not alter saved coordinates.
  4. If the transition cannot be identified: Uncertain. If hidden behind an object: Occluded. If the expected boundary lies outside the photo, or the tyre does not intersect that guide: Outside frame. Never guess. You may skip all six points.
  5. Choose No visible issue / Visible issue / Cannot assess. A visible issue needs a short location/description, e.g. “dark notch at lower-right; unsure whether dirt.” Do not diagnose depth or safety.
  6. Leave independent inspection records as Unknown / unavailable unless you actually have a record tied to this tyre. Do not collect new physical measurements for this pilot. Merely choosing “available” does not approve a healthy reference.
  7. Press Save annotation JSON after every few images and before closing. The JSON contains only labels, not photographs. To resume, reopen this same HTML and use Load saved JSON. Browser autosave is only a convenience and may be unavailable.
  8. When the counter says 12/12 reviewed, return the JSON to the assistant, or attach that JSON to Kaggle and run NB22. Stop there; wait for feedback before any larger batch or model training.

These guides are proposed operational 2-D labels, not validated anatomical landmarks or camber/toe measurements. The prototype's calibrated target workflow remains separate. No mileage classes or model predictions are displayed to influence your judgement.
